1-structure des donnees : 

   1.1- list : est une collection ordonnée. // ArrayList

garde l'ordre des éléments 
accepte les doublons 
permet d'accéder à un élément avec son index.

exemple :

import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {

        ArrayList<String> noms = new ArrayList<>();

        noms.add("Reda");
        noms.add("Amine");
        noms.add("Reda");

        System.out.println(noms);
    }
}

sortie : [Reda, Amine, Reda]

   1.2- set : est une collection qui ne permet pas les doublons. // HashSet

exemple :

import java.util.HashSet;

        noms.add("Reda");
        noms.add("Amine");
        noms.add("Reda");

        System.out.println(noms);
    }
}

sortie : [Reda, Amine]

       4.1-Exceptions vérifiées et non vérifiées:

1. Checked Exceptions: Ce sont des exceptions que Java oblige le programmeur à gérer ou à déclarer.

exemple :

import java.io.FileReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) {

        try {
            FileReader fichier = new FileReader("test.txt");
        } catch (IOException e) {
            System.out.println("Erreur avec le fichier");
        }
    }
}


IOException est une Checked Exception. car en peut avoir proble en

5- CONCURRENCE ET SYNCHRONISATION

Concurrence → plusieurs tâches travaillent en même temps.
Thread → une tâche exécutée par le programme.
Synchronisation → éviter que plusieurs threads créent des problèmes en utilisant les mêmes données.


      5.1 Multithreading: lors executrer plusieurs tâches peuvent avancer en parallèle.


	1- ExecutorService : lance 2 tache a la fois synchrone :

exemple :


public class Test {

    public static void main(String[] args) {

        Thread t1 = new Thread(() -> {
            System.out.println("Tâche 1");
        });

        Thread t2 = new Thread(() -> {
            System.out.println("Tâche 2");
        });

        t1.start();
        t2.start();
    }
}


	2- CompletableFuture permet d'exécuter des tâches de manière asynchrone.

Exemple :

CompletableFuture.runAsync(() -> {
    System.out.println("Tâche exécutée");
});

Le mot important est asynchrone.

Cela signifie que le programme peut lancer une tâche et continuer à faire autre chose sans attendre immédiatement la fin de cette tâche.




      5.2 Sécurité des threads : regle les probleme de concurance 

1-synchronized :un seul thread a la fois 

Exemple :

	public synchronized void retirer(int montant) {
    argent = argent - montant;
}



2-ReentrantLock: ait également du verrouillage, mais il donne plus de contrôle que synchronized.


exemple :

Lock lock = new ReentrantLock();

lock.lock();

try {
    argent = argent - 50;
} finally {
    lock.unlock();
}
